A reproducible test of steady hum prediction, acoustic paths and delayed anti-noise. Existing microphones and ordinary earphones remain the engineering goal.

Prediction has to survive the whole path

Noise → reference microphone → causal predictor → path compensation → output delay and unknown jitter → earphone acoustic path → simulated ear residual. The ear also receives noise the reference microphone cannot observe.

Control comparison

Points show means, whiskers show seed ranges. The oracle uses future data. FxNLMS uses an extra simulated error microphone and adapts online; the other deployable methods do not.

Timing sensitivity

Constant latency can be anticipated when a tone remains predictable. Unknown timing error rotates the anti-noise phase; improved waveform prediction alone cannot correct an unknown playback time.
